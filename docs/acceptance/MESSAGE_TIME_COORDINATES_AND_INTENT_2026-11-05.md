# 消息时间坐标与跟随意图补验

基线：`3230e8da1c7dfa87fff146b7c5daa74d350ab84d`。本轮保留通话时间与聊天末尾预绘制机制，不修改图片发送。原有未跟踪文件未纳入提交。

## 根视图坐标

Android `getGlobalVisibleRect` 返回根 View 坐标，而 `getLocationInWindow` 返回窗口坐标。Robolectric 真实 Activity/View 层级中，将 decor 根 View 下移 50px 后，实测列表窗口坐标与可视矩形相差 50px；旧实现对本来可见的尾行误报 50px 溢出。修复先将可视矩形按根 View 在窗口中的位置转换，再比较窗口内的绘制坐标。同一真实层级回归在旧实现失败、修复后通过；回归另覆盖普通布局、父容器裁切、位移、缩放和窗口偏移。实机分屏和所有厂商窗口变换未覆盖。

## 跟随意图

生产注册表回归在已记录跟随的列表中扩高尾行，然后注入无用户输入的负向 RecyclerView 回调：旧实现撤销跟随，导致预绘制补齐无法运行。这个测试证明回调处理的缺口，不证明所测微信版本一定会在真实布局中产生该回调。

修复仅在 RecyclerView 处于用户拖动状态时将负向回调直接视为历史意图；触摸手势和滚轮、列表已处理的键盘与无障碍历史导航也保留历史位置，已接受的异步历史导航立即记录意图。新测试分阶段检查自动回调仍可纠正、历史手势和拖动不能被拉回、滚轮及异步导航保护。未在真机覆盖外接键盘、鼠标或无障碍服务；宿主绕过这些标准入口的自定义导航未验证。处理成功但只改变焦点的方向键可能保守地暂停尾部跟随，用户回到底部后可恢复。
