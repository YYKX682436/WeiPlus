## 统计口径与使用方式

当前扫描到 **262 个实际 Feature 对象**，来自 **261 个文件**。其中 **218 个用户功能/操作对象**（包含 10 个调试工具、3 个上游声明未完成项），以及 **44 个 API/运行基础服务**。按 UI 声明，用户对象中 195 项有开关、23 项是点击动作/配置入口。不要宣传为 262 个成熟可搬功能。

扫描遵循当前 KSP 的源类型发现思路：枚举 `app/src/main/java` 内继承 `BaseFeature` 的具名 `object`，以完整类名去重。实际继承链覆盖 `SwitchFeature`、`ClickableFeature`、`ApiFeature` 和 `AutoMomentsBase`；不是按文件数、文档数或旧注解计数。本次未运行 KSP 编译，统计为静态对象声明核对结果。

注册规则依据：[libs/common/annotation-scanner/src/main/java/dev/ujhhgtg/wekit/features/FeaturesScanner.kt](https://github.com/Ujhhgtg/WeKit/blob/650febaa3717eddd39f5f29a4dfa6dfd37875cb1/libs/common/annotation-scanner/src/main/java/dev/ujhhgtg/wekit/features/FeaturesScanner.kt)；对象与进程/启停规则依据：[app/src/main/java/dev/ujhhgtg/wekit/features/core/BaseFeature.kt](https://github.com/Ujhhgtg/WeKit/blob/650febaa3717eddd39f5f29a4dfa6dfd37875cb1/app/src/main/java/dev/ujhhgtg/wekit/features/core/BaseFeature.kt)、[app/src/main/java/dev/ujhhgtg/wekit/features/core/ClickableFeature.kt](https://github.com/Ujhhgtg/WeKit/blob/650febaa3717eddd39f5f29a4dfa6dfd37875cb1/app/src/main/java/dev/ujhhgtg/wekit/features/core/ClickableFeature.kt)。

**后续每次选择功能：**用中文名、technicalId 或类名定位本表 → 打开固定基线源码及直接服务 → 对照 Hchat 当前实现 → 针对当前微信 APK 核对目标 → 才生成实现与验收指令。用户只说名称含糊时，应先确认行为语义，不能据标题猜功能。

表内源码路径相对 `app/src/main/java/dev/ujhhgtg/wekit/`；完整路径、各条固定提交 URL、原始名称资源、描述资源、直接引用、导入源文件、进程和 SDK 线索均存于 JSON。对大项按类名提取单条记录即可，无需每次重读全部索引。

“依赖线索”来自对象体内具名 Feature 符号与源码导入的静态扫描，不是完整动态调用图；服务调用可能经 helper/基类/反射转发，必须沿所选功能继续读。字段 `dex_resolver=false` 也不表示不依赖 DexKit，它可能通过服务间接使用。

上游 [AGENTS.md](https://github.com/Ujhhgtg/WeKit/blob/650febaa3717eddd39f5f29a4dfa6dfd37875cb1/AGENTS.md) 声明宿主验证范围是 **微信 8.0.65–8.0.78**。Hchat 当前的 8.0.80 需要重新核对结构和真机行为；本索引没有运行宿主 APK 定位检查、模块构建或真机测试。

## 必须先看清的差异

- `BlockAtAllNotifications.kt` 有设置对象和 `BlockAtAllNotificationsRuntime` 两个注册对象，但只代表一个用户功能。
- `MonetEngine`、`PredictiveBackGestures`、`JavaHookApi` 等虽然文件在 `items/`，当前仍是 API 基础服务；不能按目录名自动归入用户开关。
- `WeAgent` 继承 `ClickableFeature`，但 `alwaysEnabled=true`、`noSwitchWidget=true`，具体悬浮展示由它自己的配置控制。
- `CustomConversationNotifications.kt` 全文注释、带 TODO，不作为可用功能列入。
- “美化组件按下效果”“分享进化”“自动添加附近的人”的当前资源描述均有“没写完”，已单独标记。
- “屏蔽铃声”不等于屏蔽来电；“已读追踪”基于像素/IP 统计；“防止封号”属于娱乐项；“余额显示”不表示真实资产改变。这些名字必须和实际行为一起解释。

## 索引自身的校验与限制

- 262 个全限定类名与 technicalId 均唯一；261 个源文件均存在。
- 每条 source_line 指向对应 object 声明；所有源码/文档路径在固定快照中存在。
- 中文名由 `nameRes` 在简中 strings.xml 中解析，缺失时回退默认 strings.xml；统计中无未解析名称。
- 类别使用源码 `categoryIds`，不根据文件夹猜类别。
- API 引用为词法候选边，不能宣称包含所有反射、同包 helper、继承与动态调用依赖。配置/页类未另计功能，但 JSON 的 `resolved_import_source_paths` 给出可静态解析的导入路径。
- 本次未在 Android 中加载上游模块；没有对每项功能做可用性、安全性、性能或 Hchat 适配验收。
